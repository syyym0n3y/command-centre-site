Command Centre

Privacy Policy

Last updated 23 September 2026

Command Centre is operated by Ona Mejelo. You can reach me at ona@revitalise.io. This policy explains exactly what the application touches, where it keeps things, and how to make it stop.

Who this applies to

One operator, on YouTube channels that operator owns. There is no public sign-up and no user base. If you are reading this because a Google consent screen linked you here, the account being connected is our own.

What we access from Google

When a channel is connected, Google issues a token that lets the application act on that channel. With it we access:

  • The channel's identifier and title, so an upload is matched to the right channel.
  • Video identifiers and metadata for videos this application created — title, description, tags, thumbnail, privacy setting, publish time.
  • Performance figures for those same videos: views, watch time, average view duration, impressions and click-through rate, and subscriber changes.

We do not read your Gmail, Drive, contacts, calendar or location. Those permissions are never requested. We do not read other people's channels through this application.

What we store, and for how long

  • Connection tokens. The refresh and access tokens Google issues for each connected channel. They are what allow an upload to run without somebody sitting at a keyboard.
  • Channel and video records. Identifiers, titles, descriptions and publish times for material this application produced.
  • Performance history. Daily figures for our own videos, kept so we can tell whether a video worked.

All of it sits in a PostgreSQL database on hardware we control. It is not hosted with a cloud database provider. Records are kept while the channel is in use and deleted when the channel is removed from the application. Tokens are deleted immediately when a connection is removed or revoked.

What we never do

We do not sell data. We do not share it with anyone. We do not use it for advertising, and we do not use it to build profiles of people. No third-party analytics or tracking service is embedded in this application, and this website sets no cookies.

Limited Use

Command Centre's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Open myaccount.google.com/permissions, find Command Centre, and remove it. Access stops at once. Any stored token for that channel becomes useless, and we delete it. You can also email ona@revitalise.io and ask for every record tied to a channel to be deleted.

Security

Tokens are held on a machine under our physical control, with full-disk encryption, and are not copied to shared storage or version control. Access to the machine is limited to the operator. If a token is ever exposed, we revoke it at Google and issue a new one.

Children

This application is not directed at children and collects nothing from them.

Changes

If this policy changes, the date at the top changes with it and the previous version is kept in our revision history.

YouTube API Services

This application uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy also apply to data handled by Google.
